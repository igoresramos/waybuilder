# Pericia de Recall Knowledge

- clausulas convertidas em termo: **3**

A forma nao nomeia pericia -- pergunta se EXISTE alguma com aquele rank --, entao vira `skill:recall-knowledge`, mesmo desenho de `lore:*` e `weapon:*`. Sem isso os tres feats saiam DISPONIVEIS para quem nao podia pega-los, com o `requires` guardando so o gate de nivel.

| registro | rank exigido |
|---|---|
| `wb:feat/automatic-knowledge` | expert |
| `wb:feat/dubious-knowledge` | trained |
| `wb:feat/masterful-obfuscation` | master |
